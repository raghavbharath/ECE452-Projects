# High Performance Computing (HPC) Projects

Repo for ECE 452 projects. Each project has its own branch with its own README and code.

**Project 1** - Built and trained a custom MLP for handwritten digit recognition. Used PyTorch for training and a custom NumPy inference engine for testing. Also extended it to MATLAB for the full MNIST dataset and compared different activation functions. 

**Project 2** - Benchmarked GEMM (General Matrix Multiplication) across CPU and GPU implementations to study cache-aware tiling and hardware acceleration. Compared pure Python loops, NumPy, and NVIDIA cuBLAS on a Tesla T4 GPU. 

Feel free to check out the `project-1` and `project-2` branches for more!
